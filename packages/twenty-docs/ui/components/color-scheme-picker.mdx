`ColorSchemePicker` displays three appearance previews. Your application owns the selected value and the labels.

  storyId="ui-input-colorschemepicker--default"

/>

```tsx
import { useState } from 'react';
import { ColorSchemePicker } from 'twenty-ui/components';
import { type ColorScheme } from 'twenty-ui/primitives/input';

export const AppearancePicker = () => {
  const [value, setValue] = useState<ColorScheme>('Light');

  return (
    <ColorSchemePicker
      value={value}
      onChange={setValue}
      lightLabel="Light"
      darkLabel="Dark"
      systemLabel="System settings"
    />
  );
};
```

Each label is both visible text and the accessible name of its choice. Supply localized `lightLabel`, `darkLabel`, and `systemLabel` values. Selection callbacks still receive `Light`, `Dark`, or `System`.
